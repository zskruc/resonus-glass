# Resonus Glass：功能与验证范围

这是 Resonus 的非官方 Android 玻璃界面分支。当前公开基线为 Android 更新编号 66，基于既有 Glass 定制并选择性移植上游修复，并非完整的上游 0.8.4。

## 玻璃材质

原生模块使用 AndroidLiquidGlass / Backdrop 1.0.0。每个窗口共享背景采样，控件只绘制各自的背景区域。Android 13 及以上支持折射和定向高光；Android 12 保留 GPU 模糊；不支持的系统使用界面层回退。Expo Go 无法加载本地模块。

mini player 不添加固定填充色，也不从当前歌曲封面提取染色。透过玻璃看到的色彩来自其下方页面；歌曲缩略图正常保留。展开态和折叠态使用同一组保存的光学参数，背景来源可随底栏布局变化。

设置中的调节界面分别保存 mini player、导航和其他控件的配置。示意参考模式是本项目的近似材质预设，不代表 Apple 未公开的参数。

## 布局与交互

- 展开态显示独立 mini player 和底部导航，搜索位于右侧。
- 满足连续同方向拖动门槛后，mini player 与导航联动折叠或展开；惯性滚动不会单独完成短拖动触发。
- 主列表及艺人、专辑、播放列表等详情页使用共享滚动处理；水平列表和弹出菜单不驱动底栏。
- 展开时，整屏宽度的底部渐进模糊从导航上方开始，mini player 两侧保留原页面背景。
- 歌曲菜单、信息、速度和相关弹窗使用统一圆角玻璃；普通播放按钮保留直接图标形式。

## 性能与可访问性

玻璃共享 GPU 背景和缓冲区，采样区域限制为可见材质范围，动画避免逐帧改变 React Native 布局。路由、弹窗和录制状态各自管理背景生命周期，防止旧页面封面闪现、递归采样及拖动时的背景错位。系统减少动态效果选项和字体粗细调整继续生效。

实现没有固定的 24/60 fps 滚动采样上限，但实际帧率受设备、系统调度、场景和功耗状态影响。显示器支持 120 Hz 不等于应用或背景采样持续达到 120 fps。

## 当前验证

公开基线通过 TypeScript、翻译一致性检查、227 项应用测试及完整 ARM64 Android 发布构建。原生模块的相关回归还覆盖页面采样时序、几何变化及车机封面/队列映射。此前的定制版本已在 Android 实机验证主要玻璃布局、滚动和弹窗交互；本次新增的上游修复安装包完成构建，仍需要安装后的设备验收。

这不是所有设备或所有界面的性能保证。iOS、旧版 Android 回退和外部 `SurfaceView` 内容不属于同等验证范围。应用登录资料、离线下载、签名密钥、设备截图和本地诊断记录不包含在源码仓库中。

## 上游修复范围

当前版本选择性移植了后台返回状态恢复、转码播放时长、歌词时间排序、搜索容错、服务器完整响应超时及媒体封面认证信息隔离等修复。保留本分支既有的玻璃材质、折叠交互、网络恢复和音频定制；没有整体替换为上游最新版本。
