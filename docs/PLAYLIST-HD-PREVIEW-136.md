# 歌单高清封面与旧缓存升级

`0.8.5.2-preview.4` · Android `versionCode 136` · 本地测试版，未发布 Release。

## 问题与修复

高清自定义歌单封面在服务器端可正常提供 1200×1200 图片，但旧版详情页仍可能显示较小的本地缓存。

此前 App 自动镜像统一缓存 600px 图片，取图时无条件优先使用本地图。歌单大图即使指定 1200px，也可能被 600px 文件替代。直接覆盖相同文件还可能继续命中图片解码缓存。

本轮让歌单详情、编辑预览及大图查看使用 1200px；在线时跳过分辨率不足或未知的旧本地图。正常载入歌单列表和详情时，旧封面自动升级到 1200px，新的文件路径和持久尺寸记录让已打开页面及下次启动都能使用高清图。升级成功前保留旧图，离线继续使用已有图片。旧小图在升级后也保留为已打开卡片的兼容文件，计入存储用量，删除该封面缓存或清理账号时一同回收。

自动下载继续受当前账号、离线模式、播放加载优先级及共享网络并发限制约束。歌单歌曲、播放历史、离线音乐和 NAS 原封面不在本轮修改范围。
