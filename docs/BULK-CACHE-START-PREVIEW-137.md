# 批量缓存任务启动与网络复核

`0.8.5.2-preview.5` · Android `versionCode 137` · 本地测试版，未发布 Release。

## 已确认的问题

离线模式下，“继续”和“扫描所选项”原先没有点击处理，外观却容易被误认为仍可操作。另有已在真实 store 回归框架中复现的问题：启动预检会先用旧的断网或蜂窝快照拒绝任务，导致当前已恢复 Wi-Fi 时也无法进入实时检测。

本轮在明确启动或继续时先尊重手动离线、账号归属及 Android 后台保护，再取得实时网络结果。期间的新网络事件不会被较早返回的检测覆盖，后续真实断网和仅 Wi-Fi 限制仍然生效。无法启动时显示明确原因，准备期间提供加载反馈。

“继续”保留当前任务和检查点；“扫描所选项”仍是重新建立增量扫描。已有封面、歌词和离线音频文件不会因建立新扫描而删除。

## 与歌单高清封面的关系

包含 [preview.4 的歌单高清取图和旧缓存升级](./PLAYLIST-HD-PREVIEW-136.md)。三星已验证旧 600×600 缓存可自动升级到实际 1200×1200，原缓存和离线音频保持。离线冷启动、大图查看及后台返回均显示完整高清图片。

ListenBrainz 自动拼图的来源仍只有 599×599；请求 1200px 也不会增加它的真实细节。这与 16 张自定义歌单的缓存降级问题不同，若需要更清楚的拼图，应另换更高分辨率的来源。
